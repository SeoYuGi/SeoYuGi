# 도플갱어 (DOPPLEGANGGER)

**팀명: 서유기**

AI 아군을 직접 언어로 지휘하는 실시간 턴제 거점 점령 게임.
유저 한 명이 지휘관이 되어 AI 아군 둘에게 채팅 또는 음성으로 지시하고, LLM이 그 말을 유닛별 명령으로 바꿔 아군이 실제로 움직인다.

## 키워드 해석

| 키워드 | 해석 |
|---|---|
| 2026 | AI 아군과 협력하면서 동시에 AI 적군(모방 로봇)을 상대한다 |
| 영역 | 도시 뒷골목 동물들의 거점 점령 싸움 |
| 예측 | 모든 공격은 예고 뒤에 판정된다. 상대가 피할 자리를 예측해서 공격한다 |

## 핵심 시스템

- 3 vs 3 실시간 턴제 전투. 그리드 이동, 공격 예고, 쿨다운
- 거점 점령. 탈환, 감쇠, 경합 동결, 인원 보너스
- 지휘관 모드. 작전 타임과 무전 타임에 게임을 멈추고 자연어로 지휘
- LLM 무전. 명령을 봇의 목표, 태세, 타깃, 복종 여부로 번역. 캐릭터별 성격과 불복종
- 폴백. API 실패 시 숫자키 프리셋(1~7)으로 동일하게 진행
- 싱글(봇 3기 상대), 멀티(유저 2명이 각자 봇 2기 지휘), 튜토리얼, 훈련장
- 라운드마다 바뀌는 랜덤 규칙 6종

## 실행

`도플갱어빌드.zip`을 압축 해제하고 실행 파일을 실행한다. LLM 무전에 쓰는 API 키는 빌드에 포함되어 있어 별도 설정이 필요 없다.

## 개발 환경

- Unity (URP), C#
- 전투 코어는 순수 C#으로 분리해 엔진 없이 컴파일과 시뮬레이션 검증
- LLM 무전: OpenAI API (텍스트, 음성)
