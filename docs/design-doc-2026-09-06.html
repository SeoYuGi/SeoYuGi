0문서 목적과 읽는 법

이 문서는 2026-09-06 현재 실제로 코드에 구현되어 동작하는 것만 모아 정리한 총정리 기획서다. 수치는 전부 코드 상수와 데이터 테이블에서 옮겼고, 주석이나 옛 기획서와 어긋나는 곳은 코드 값을 기준으로 삼았다. 기획 변경은 더 없고 UI 작업만 남았다는 전제로, 14장(UI 인벤토리)과 15장(확인 요망)을 UI 작업 전에 먼저 훑어보면 된다.

표기 규칙
  • 동물팀 = 팀 0 (틸/파랑 계열). 호스트, 싱글 플레이어가 속한다.
  • 기계팀 = 팀 1 (주황/빨강 계열). 같은 동물 모델을 은색 금속 재질로 바꾼 "기계 동물".
  • 거리 표기: 체비쇼프 = 대각 포함 정사각 반경. 맨해튼 = 십자 거리(다이아 모양).
  • OnGUI = 코드 즉시 드로잉 임시 UI. uGUI = 프리팹 기반 UI. 월드 = 3D 공간 오브젝트.

2.2 매치 흐름

  1. 맵 랜덤 확정. 6장 중 하나. 맵 선택 화면은 제거됨.
  2. 캐릭터 선택 (30초 제한, 종료 시 현재 선택으로 자동 출격). 싱글은 나 → 팀원1 → 팀원2 순으로 3픽. 봇 클래스는 내 픽 기준으로 탱/돌격/딜 축을 자동 보정. AI 난이도 상/중/하는 적팀 봇에게만 적용된다. 적팀 조합은 시드 롤(중복 없음)이며 비공개.
  3. 라운드 시작: 3초 카운트다운(첫 판 가이드는 5.5초). 지휘관 모드면 분대원 둘이 잡담 한 줄씩. 규칙이 있으면 분대가 규칙에 반응해 스스로 초기 명령을 잡는다.
  4. 전투 120초(단축 작전 규칙이면 90초).
  5. 라운드 종료 연출: 결정타 주인공(마지막 처치자 또는 점령자)에게 킬캠 클로즈업 + 0.25배속 2.1초 + 사유 대문짝 + 히어로 카드.
  6. 라운드 결과 화면: 거점 소유 A/B/C, 양 팀 생존 수, 팀별 K/D 전적, 종료 사유. SPACE 동의 게이트(멀티는 전원 준비 시 진행).
  7. 2라운드마다 맵 로테이션(R1, R2는 같은 맵, R3는 다음 맵). 매치 승자가 나오면 매치엔드 2페이지: ① 초상 통계 스트립(콜사인, K/D) ② MVP 시네마틱(킬/화력/점령 다부문). R 동의 시 새 매치(싱글은 픽창, 멀티는 로비로).

5이동과 지형

5.1 실시간 이동 게이지 (탱고파이브식)

  • 유닛마다 이동 게이지(0 ~ freeRange)가 초당 회복된다. 회복 지연(regenDelay)은 전 클래스 0초.
  • 파랑 이동: 진입 비용 합이 현재 게이지 이내. 게이지만 소모, 즉시 다음 행동 가능.
  • 노랑 이동: 게이지 초과 ~ maxRange. 게이지 0 + 노랑 쿨타임(이동 불가). 쿨 종료 시 풀 게이지로 복귀.
  • 진입 비용: 평지 1, 고지대 2. 경로는 BFS(십자 이동), 다른 유닛 칸은 막힘.
  • 시전 중 이동 금지: 내 예고(평타 포함)가 판정 대기 중이면 이동 범위가 안 뜨고 이동이 거부된다.
  • 스턴 중, 비행 중(낚아채기 시전) 이동 불가.
  • 이동 범위 표시: 파랑/노랑 네온 테두리 두 겹, 호버 칸에 발자국 아이콘. 이동 경로가 힐팩을 지나면 멈추지 않아도 먹는다.

9.5 성격과 복종

  • LLM 응답에 compliance: obey / question(되묻고 명령 비움) / refuse(명백한 자살행위만, 대안 제시). 거부와 반문은 기존 명령 유지.
  • 복합 명령("너굴은 까돌봇 잡고, 나머지는 날 따라와")은 분대원별 명령 + 분대원별 응답(acks, 최대 3).
  • 호칭 유동 인식: 별명, 동물 이름, 기계 이름, 클래스명, 역할, "상대 지휘관" 전부.
  • 프리셋 경로의 복종 주사위: 고라니 30% 거부(그 유닛만 자율 + 돌격), 비둘기 60% 툴툴(명령은 그대로).
  • 명령을 받은 봇 머리 위에 플로팅 텍스트("B 거점으로!", "집결!", "까돌봇 노려!" 등)로 복종을 가시화.

9.6 핑 지휘

  • 휠클릭 탭 = ▼(집결), 휠 꾹 누르고 끌기 = ▼ / ! / ? 선택 휠. 핑 칸은 누른 순간 기준.
  • 같은 팀 봇이 6초간 복종: ▼ = 그 칸으로 집결, ! = 근처 적 집중 타겟. ? = 정보 공유만.
  • 지휘관이 적 유닛이 서 있는 정확히 그 칸을 핑하면 팀 봇 전체가 그 적을 6초 하드 포커스.
  • 멀티는 같은 팀 사람에게만 배달. 적팀 핑은 보이지 않는다.

10.1 판단 우선순위

  2. 해킹 게이지 만충 시 발동.
  3. 1.5) 개막 카운터: 러시 습관 감지 시 시작 6초 안에 반복 진입로에 선제 설치(R2 이상).
  4. 공격/스킬: AttackInterval 페이싱, ±30% 지터. 조준은 반응 지연(AimReactionDelay 0.5초, 난이도별 0.3~0.8)을 먹인 칸. 적팀은 예측기 top-1 칸에 예고를 깔 수 있음("예측 사격", 보라 기둥 연출). 지휘 Evasive면 먼저 쏘지 않음.
  5. 패배 긴급: 적이 거점을 더 쥐면 대치/고지 사수/힐팩 다 접고 거점으로.
  6. 3.1) 거리 유지(원거리 KeepDistance) → 3.2) 근접 대치 자리 사수 → 3.5) 습성 카운터 포지셔닝(R2+) → 3.6) 핑 집결 → 3.7) 힐팩 추구.
  7. 지휘 명령이 있으면 거점 자동 선택 대신 명령 목적지로(BFS 경로, 위협 회피는 그대로).
  8. 거점 이동: 미소유/열세 거점으로. 아군이 붙은 거점 선호(CohesionBonus). 먹을 거점이 없으면(전부 봉쇄/굳음) 가장 가까운 적 사냥.

15확인 요망 (놓친 부분 후보)

코드를 읽으며 발견한, 기획 변경은 아니지만 UI 작업 전에 결정하거나 정리하면 좋은 항목이다. 판단은 사용자 몫이라 고치지 않고 나열만 했다.

15.1 기능 흐름의 빈 곳

  • 전투 중 타이틀로 돌아가는 버튼이 없다. 일시정지 메뉴는 계속하기 / 설정 / 게임 종료(앱 종료)만 있다. 튜토리얼 완료 공지가 "ESC 메뉴에서 타이틀로"라고 안내하지만 그 버튼이 없다. 훈련장 안내 "ESC 메뉴로 나가기"도 같은 문제. 매치엔드에서는 R → 픽창 → ESC로만 타이틀에 갈 수 있다. (PauseMenu.cs, BattleRunner.EndRadioTime)
  • 타이틀 전용 설정 화면이 없다. 타이틀 설정 버튼이 일시정지 메뉴의 OnGUI 설정을 띄운다. 해상도, 전체화면, 키 안내 같은 항목도 없다.
  • 훈련장은 UI 모드 표기가 Multi다. 무전창이 안 뜨는 것은 의도이지만, HUD 상단에 ROUND 1/3, 거점 칩, 타이머(멈춘 값)가 그대로 그려진다. 훈련장용 HUD 축소가 필요한지 확인.
  • 매치엔드 이후 싱글은 픽창으로만 간다(맵 재선택 없음, 랜덤 맵은 유지). 의도면 OK.
  • 멀티에서 지휘관 대전이 꺼진 Multi 모드는 무전, 무전 타임, 브리핑이 전부 없고 퀵챗은 채팅만이다. 즉 봇 2기는 완전 자율. 로비 토글 기본값을 확인.

15.2 문구/데이터 불일치

  • 카드 스킬 설명 "저격: 1열 관통"은 구 규칙이다. 현재 조준 사격은 다이아 + 십자 끝 지정, 관통 없음, 벽 시야선 필요. (ClassCard.SkillDesc) 카드 설명은 코드 하드코딩이라 UI 작업 시 같이 고쳐야 한다. 다른 설명("전방 밀치기", "5칸 투척, 벽 충돌", "돌진, 충돌 스턴", "주변 스턴", "3칸 점멸", "근접 강타", "십자 폭격, 둔화", "적 끌어오기", "밀치는 사격")은 현행과 맞다.
  • 코드 주석의 옛 수치가 여러 곳에 남아 있다(예: 조준 사격 피해 3이라 적힌 enum 주석, 실값 4 / 파열탄과 도약 "5×5" 주석, 실값 체비쇼프 3 = 7×7 / 고지대 시야 "+1" 주석, 실값 +2 / AttackShape 이름 Melee8, Circle2, Square2는 옛 크기). 동작에는 영향 없음. 카드/HUD 수치는 데이터에서 읽으므로 화면은 맞다.
  • 기계팀 카드 아트가 두 세트다: Card_*_M(코드가 찾는 이름)과 Card_M_*. 후자는 미사용 가능성.
  • 기계 GLB 5종(cleaning_bot 등)이 Resources에 있지만 스킨 매핑은 동물 모델 + 은색 재질만 쓴다. 미사용 에셋.
  • Icon_Guard: 방어 기능은 삭제됐다. 아이콘 미사용.
  • QuickChat 주석 "해킹 발동 시 자동 전송. 매치 1회뿐인 필살기"는 게이지제 이전 표현이다. 동작(쿨 무시 자동 전송)은 유효.

  • Unity UI는 코드 드로잉 대신 UIManager 프리팹으로. 필요한 에셋은 Assets.md 참고 후 임포트 요청.
